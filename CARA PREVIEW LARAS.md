# Preview LARAS UMKM di komputer

1. Klik dua kali **Buka Preview LARAS.cmd** di folder proyek.
2. Tunggu browser terbuka. Pada layar komputer, aplikasi ditampilkan dalam bingkai selebar ponsel.
3. Gunakan tombol **Masuk ke akun demo LARAS UMKM**, lalu jelajahi menu dan catat bagian yang ingin diubah.

Alamat lokal: http://127.0.0.1:43827/ . Alamat ini hanya tersedia pada komputer ini ketika server preview berjalan. Jika server belum berjalan, klik lagi file pembuka.

Preview menggunakan kode Flutter aplikasi yang sama dan versi release, sehingga setelah dibangun tidak membutuhkan emulator atau proses debug Flutter. Saat kode berubah, klik lagi file pembuka untuk membuat ulang preview; proses membangun dapat memerlukan waktu beberapa menit. Setelah siap, muat ulang tab browser jika diperlukan.

Data yang dicoba di preview disimpan di browser pada komputer ini dan terpisah dari data APK di HP. Kamera, pembacaan struk dengan OCR, gambar QRIS, dan fitur cetak dapat berperilaku berbeda atau tidak tersedia di browser. Tampilan akhir, izin, serta fungsi khusus Android tetap perlu diperiksa pada perangkat Android.
